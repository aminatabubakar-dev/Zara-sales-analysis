# Zara Sales Analysis – Power BI

## About the Project

This project analyzes Zara sales data using Power BI to identify sales patterns and generate business insights.

### Tools Used

* Power BI
* Power Query
* DAX
* Excel

### Key Metrics

*Total Revenue:₦849.55K
*Total Sales Volume:1.284K

### Key Insights

* Jackets generated the highest sales among the product categories.
* The Women section accounted for a larger share of sales than the Men section.
* Autumn recorded the highest seasonal sales.
* Products without promotions generated a larger share of sales than promoted products.
* Aisle products had the highest sales among the product positions analyzed.
* China recorded the highest sales by product origin.

### Recommendations

The analysis suggests focusing inventory on high-performing products, planning stock around seasonal demand, using promotions more selectively, and reviewing lower-performing products and sections.

### Dashboard

The dashboard provides an interactive view of revenue, sales volume, promotions, sections, product positions, seasons, categories, and origins.
